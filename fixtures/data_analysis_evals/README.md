# Synthetic development CSVs

`development/` contains ten CSVs and fifteen public task questions. All data is invented.
The input manifest records exact file hashes, schemas, and row counts.

See [CSV fields, questions, and running instructions](../../docs/evaluation/Running.md).
These public examples are for development. Reserve separate unseen files for a final study.
Expected answers are calculated by the host-only evaluator and are not sent to models.
